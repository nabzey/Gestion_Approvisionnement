📋 Contexte du Projet

Réalisation d'une API RESTful avec Node.js et Express pour gérer les approvisionnements d'une boutique. L'application gère trois entités principales : Fournisseur, Produit et Approvisionnement.

🏭 Fournisseurs

Gestion complète du cycle de vie des fournisseurs avec validation et recherche.

Endpoints:

  • POST /api/fournisseurs - Créer
  • GET /api/fournisseurs - Liste
  • GET /api/fournisseurs/:id - Détails
  • PUT /api/fournisseurs/:id - Modifier
  • DELETE /api/fournisseurs/:id - Supprimer

📦 Produits

Gestion du catalogue avec upload d'images sur Cloudinary et gestion des stocks.

Endpoints:

  • POST /api/produits - Créer (+ image)
  • GET /api/produits - Liste
  • GET /api/produits/:id - Détails
  • PATCH /api/produits/:id/increment - + Stock
  • PATCH /api/produits/:id/decrement - - Stock

📊 Approvisionnements

Enregistrement des approvisionnements avec mise à jour automatique du stock.

Endpoints:

  • POST /api/approvisionnements - Créer
  • GET /api/approvisionnements - Liste
  • GET /api/approvisionnements/:id - Détails
  • PUT /api/approvisionnements/:id - Modifier
  • DELETE /api/approvisionnements/:id - Supprimer

🎯 Fonctionnalités Clés

  • Upload Cloudinary : Les images des produits sont uploadées sur Cloudinary via Multer
  • Gestion du Stock : Le stock est automatiquement mis à jour lors des approvisionnements
  • Validation Joi : Validation robuste des données avec Joi
  • Architecture MVC : Pattern Repository avec couche de service
  • Swagger : Documentation API complète avec Swagger UI
  • Error Handling : Gestion centralisée des erreurs
  • Middleware Async : Gestion des erreurs asynchrones
  • Protection Stock : Empêche les stocks négatifs (HTTP 400)
